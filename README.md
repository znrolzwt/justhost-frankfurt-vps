## 国内访问：211ms 是什么水平

以下数据来自 2022 年 10 月的一次第三方测试，92 个国内节点，晚 10 点测。不是当前实测，只能当量级参考。

全网平均 **211.2ms**。分运营商看，电信 204.8ms、联通 204.2ms、移动 241.9ms；移动明显吃亏。92 个节点里最快的是北京腾讯云轻量 148.6ms，最慢的江苏南通移动 316.3ms。分区域，华北 201.7ms 最好，西南 220.2ms 最差，华东 212.4ms、华中 216.1ms、东北 216.7ms，各区间差距不到 20ms。

丢包同一时段：移动、联通各约 1%，电信约 7%。电信这个数字偏高，晚高峰对稳定性敏感的应用要留心。测速那边，三网上传都不好看，下载基本能跑满带宽，拿它做下载源比做上传端合适。

路由走向：

- **去程**：电信走 163 骨干直连德国；联通经 169 骨干接 Telia 走瑞典方向；移动走香港 CMI 再转出去。
- **回程**：三网基本直连。电信经 DE-CIX 法兰克福转回国内 163，联通经 GTT 转 4837，移动经 Level3 转 58453 回国。

例外是厦门电信，回程绕了英国伦敦（Telstra）再经新加坡回国，延迟抬到 400ms 以上。个别地区绕路这种事，任何法兰克福机房都可能碰到，买之前用官网的 Looking Glass 自己 ping 一下你所在城市的节点，比看别人的图靠谱。

211ms 的实际体感：SSH、跑脚本、挂后台服务、定时任务、海外 API 中转，没什么问题。用国内网络打开上面跑的网站，首屏会明显比香港、日本节点慢；远程桌面、实时语音、游戏这类对往返延迟敏感的，不适合。
